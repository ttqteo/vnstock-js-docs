---
title: Bar
description: Một cây nến OHLCV.
---

```ts
interface Bar {
  time: string;          // "2026-10-20" hoặc "2026-10-20T09:15:00+07:00"
  open: number;
  high: number;
  low: number;
  close: number;
  volume: number;        // số cổ phiếu
  value: number | null;  // giá trị giao dịch, đồng
}
```

Trả về bởi `vn.stock(symbol).history()` và `vn.index(symbol).history()`, mảng cũ trước mới sau.

| Trường | Ý nghĩa |
|---|---|
| `time` | Giờ Việt Nam. Nến ngày, tuần, tháng: `YYYY-MM-DD` (tuần, tháng đóng dấu bằng phiên đầu). Nến trong phiên: ISO có `+07:00` |
| `open`, `high`, `low`, `close` | Giá bằng **đồng** với cổ phiếu, **điểm** với chỉ số |
| `volume` | Khối lượng của riêng nến |
| `value` | Nến ngày trở lên: giá trị giao dịch của riêng nến. Nến trong phiên: giá trị **luỹ kế** từ đầu phiên. `null` khi nguồn không có |

## Ví dụ

```json
{ "time": "2026-10-20", "open": 57000, "high": 57800, "low": 56800, "close": 57600, "volume": 3259200, "value": 186521720000 }
```
