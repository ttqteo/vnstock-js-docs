---
title: TopMover
description: Mã tăng, giảm mạnh trong phiên.
---

```ts
interface TopMover {
  symbol: string;
  exchange: string;
  price1DayAgo: number | null;    // đồng
  price5DaysAgo: number | null;   // đồng
  price20DaysAgo: number | null;  // đồng
  marketCap: number | null;
  liquidity: number | null;
}
```

Trả về bởi `vn.topMovers({ limit })` dưới dạng `{ gainers: TopMover[]; losers: TopMover[] }`, mặc định 10 mã mỗi bên.

## Ví dụ

```json
{
  "gainers": [{ "symbol": "BHH", "exchange": "UPCOM", "price1DayAgo": 17400, "price5DaysAgo": 18800, "price20DaysAgo": 15300 }],
  "losers": [{ "symbol": "LAF", "exchange": "HOSE", "price1DayAgo": 18000, "price5DaysAgo": 17800, "price20DaysAgo": 19850 }]
}
```

<Note>
`marketCap` và `liquidity` đang giữ nguyên số VietCap trả về, chưa quy ra đồng như các trường khác. Đừng cộng trừ chúng với số liệu bằng đồng.
</Note>

Muốn tự xếp hạng theo phần trăm thay đổi trong phiên, lấy bảng giá cả sàn rồi sắp xếp:

```ts
import { vn } from "vnstock-js";

const board = await vn.prices({ exchange: "HOSE" });
const top = board.filter((q) => q.volume > 0).sort((a, b) => b.changePct - a.changePct).slice(0, 10);
```
