Trả về bởi `vn.screen()`.

```ts
interface ScreenRow {
  symbol: string;
  companyName: string;
  companyNameEn: string;
  industry: string;
  industryEn: string;
  exchange: string;
  price: number;          // đồng
  priceChange: number;    // đồng
  changePercent: number;  // phần trăm
  volume: number;
  value: number;          // giá trị giao dịch của phiên, đồng
  marketCap: number;      // vốn hoá, đồng
  pe: number | null;
  pb: number | null;
  ps: number | null;
  roe: number | null;     // phân số: 0.15 là 15%
  roa: number | null;
  // các trường đã dùng trong where/sort cũng có mặt, ví dụ roic, grossMargin, dividendYield
}
```

## Ví dụ

```ts
import { vn } from "vnstock-js";

const rows = await vn.screen({ group: "VN30", where: { pe: { lt: 15 }, roe: { gt: 0.15 } }, sort: "-roe", limit: 5 });
for (const r of rows) {
  console.log(r.symbol, r.pe?.toFixed(1), ((r.roe ?? 0) * 100).toFixed(1) + "%", (r.marketCap / 1e9).toFixed(0) + " tỷ");
}
```
