## CompanyProfile

Trả về bởi `vn.stock(symbol).company()`.

```ts
interface CompanyProfile {
  symbol: string;
  id: string;
  issuedShares: number;   // số cổ phiếu lưu hành
  history: string;        // lịch sử hình thành
  historyEn: string;
  profile: string;        // giới thiệu
  profileEn: string;
  industry: string;
  industryEn: string;
  sector: string;
  sectorEn: string;
  subIndustry: string;
  subIndustryEn: string;
}
```

Trường nguồn không có thì là chuỗi rỗng.

## Shareholder

`shareholders()`: cổ đông lớn.

```ts
interface Shareholder {
  id: string;
  symbol: string;
  name: string;
  nameEn: string;
  quantity: number;     // số cổ phiếu nắm giữ
  percentage: number;   // tỷ lệ sở hữu, phân số: 0.068 là 6,8%
  updatedAt: string;    // ngày nguồn cập nhật
}
```

`percentage` theo số liệu nguồn công bố tại `updatedAt`, nên có thể lệch nhẹ so với `quantity / issuedShares` khi công ty vừa phát hành thêm.

## Officer

`officers()`: ban lãnh đạo, gồm `name`, `position`, `positionEn`, `positionShort`, `quantity` (số cổ phiếu nắm giữ), `ownership` (phân số), `updatedAt`.

## CorporateEvent

`events()` (mọi sự kiện) và `dividends()` (chỉ cổ tức).

```ts
interface CorporateEvent {
  id: string;
  symbol: string;
  title: string;            // "Phát hành cổ phiếu - Cổ phiếu thưởng tỉ lệ 10.0%"
  titleEn: string;
  eventType: string;        // mã loại sự kiện
  eventTypeName: string;    // "Phát hành cổ phiếu"
  eventTypeNameEn: string;
  ratio: number | null;     // tỷ lệ, phân số: 0.1 là 10%
  value: number | null;     // giá trị tiền mặt nếu có, đồng
  publishedAt: string;      // ngày công bố
  issuedAt: string;         // ngày thực hiện
  recordDate: string;       // ngày đăng ký cuối cùng
  exRightDate: string;      // ngày giao dịch không hưởng quyền
  sourceUrl: string;
}
```

Ngày dạng `YYYY-MM-DD` theo giờ Việt Nam. Xem thêm mục Academy về [ngày giao dịch không hưởng quyền](/docs/academy/ex-date).

## StockNews

`news()`: tin của riêng công ty, gồm `title`, `summary`, `sourceUrl`, `imageUrl`, `publishedAt`.
