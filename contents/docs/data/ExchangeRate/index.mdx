## GoldQuote

`vn.gold()` trả `{ source: "btmc" | "giavangnet", unit: "VND/luong", items: GoldQuote[] }`.

```ts
interface GoldQuote {
  name: string;               // "VÀNG MIẾNG SJC (Vàng SJC)"
  code: string;               // mã sản phẩm (chỉ GiaVang.net)
  karat: string;              // "24k"; trống với bạc
  buy: number | null;         // đồng/lượng
  sell: number | null;        // đồng/lượng
  buyChange: number | null;   // thay đổi so với lần trước, đồng
  sellChange: number | null;
  updatedAt: string;          // giờ Việt Nam
}
```

```json
{ "name": "VÀNG MIẾNG SJC (Vàng SJC)", "code": "", "karat": "24k", "buy": 138600000, "sell": 142600000, "buyChange": null, "sellChange": null, "updatedAt": "2026-10-20T12:19:00+07:00" }
```

1 lượng = 10 chỉ = 37,5 g. Mỗi sản phẩm chỉ có một dòng, giá mới nhất.

## FxRate

`vn.fx({ date })` trả `FxRate[]` của Vietcombank.

```ts
interface FxRate {
  currencyCode: string;       // "USD"
  currencyName: string;       // "US DOLLAR"
  buyCash: number | null;     // đồng trên một đơn vị ngoại tệ
  buyTransfer: number | null;
  sell: number | null;
}
```

```json
{ "currencyCode": "USD", "currencyName": "US DOLLAR", "buyCash": 25650, "buyTransfer": 25680, "sell": 26060 }
```
