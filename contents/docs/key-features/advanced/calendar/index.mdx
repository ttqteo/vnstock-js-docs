---
title: Lịch Giao Dịch - Calendar
description: Ngày giao dịch, ngày nghỉ lễ, phiên kế tiếp và phiên trước.
---

```ts
import { vn } from "vnstock-js";

await vn.calendar.isTradingDay("2026-10-14"); // true
await vn.calendar.isTradingDay("2026-09-02"); // false, Quốc khánh
await vn.calendar.next("2026-09-01");         // "2026-09-03"
await vn.calendar.previous();                  // phiên trước hôm nay
await vn.calendar.holidays(2026);              // ["2026-01-01", ...]
```

| Hàm | Trả về |
|---|---|
| `isTradingDay(date)` | `true` nếu là ngày thường không trùng ngày nghỉ |
| `next(date?)` | Ngày giao dịch đầu tiên sau `date` (mặc định hôm nay) |
| `previous(date?)` | Ngày giao dịch gần nhất trước `date` |
| `holidays(year)` | Ngày nghỉ của năm, `YYYY-MM-DD` |

Ngày dạng `YYYY-MM-DD`, tính theo giờ Việt Nam. Lịch nghỉ tải từ GitHub ở lần dùng đầu và cache trong `Storage`. Ngày sai định dạng ném `InvalidParameterError`.

Giờ giao dịch HOSE: khớp lệnh liên tục 9:15 tới 11:30 và 13:00 tới 14:30, ATC 14:30 tới 14:45, thứ Hai tới thứ Sáu.
