title: Watchlist
description: Danh sách mã theo dõi lưu ở ~/.vnstock-js, dùng qua CLI và MCP.
---

Từ 2.0, watchlist không còn nằm trong SDK. Nó được dùng qua CLI `vnstock watchlist` và tool MCP `watchlist`, lưu ở `~/.vnstock-js/watchlist.json` (cùng file với bản 1.x, nên danh sách cũ vẫn còn).

## CLI

```bash
vnstock watchlist create bank
vnstock watchlist add bank VCB TCB MBB ACB
vnstock watchlist list bank
vnstock watchlist quote bank          # bảng giá mọi mã trong danh sách
vnstock watchlist remove bank ACB
vnstock watchlist delete bank
vnstock watchlist                     # liệt kê các danh sách
```

Thêm `--json` để lấy dữ liệu cho script.

## MCP

Tool `watchlist` nhận `action` (`list_all`, `list`, `create`, `delete`, `add`, `remove`, `quote`), `name` và `symbols`. Ví dụ hỏi: "Thêm VCB, TCB vào danh sách bank rồi cho tôi giá".

## Trong code

Trong ứng dụng của bạn, một watchlist chỉ là danh sách mã. Lưu nó ở đâu tuỳ bạn (database, localStorage, cookie) rồi lấy giá bằng một request:

```ts
import { vn } from "vnstock-js";

const symbols = ["VCB", "TCB", "MBB"];
const quotes = await vn.prices(symbols);
const stop = vn.watch(symbols, (t) => console.log(t.symbol, t.price));
```
