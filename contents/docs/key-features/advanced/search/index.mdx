---
title: Tìm Kiếm - Search
description: Tìm mã theo ký hiệu hoặc tên công ty.
---

```ts
import { vn } from "vnstock-js";

const banks = await vn.search("ngân hàng", { limit: 5 });
const fpt = await vn.search("FPT");
```

Tìm theo mã, tên công ty (tiếng Việt có dấu hoặc tiếng Anh) và tên ngành, không phân biệt hoa thường. Thứ tự: mã khớp chính xác, mã bắt đầu bằng từ khoá, tên bắt đầu bằng từ khoá, rồi các kết quả chứa từ khoá. Mặc định trả 10 kết quả. Kết quả là danh sách mã như [Danh mục mã](/docs/key-features/advanced/listing). `search` đọc danh mục đã cache nên không gọi mạng sau lần tải đầu.
