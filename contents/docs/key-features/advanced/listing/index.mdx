---
title: Danh Mục Mã - Symbols
description: Danh sách mã theo sàn, nhóm, ngành.
---

```ts
import { vn } from "vnstock-js";

const all = await vn.symbols();
const hose = await vn.symbols({ exchange: "HOSE" });
const vn30 = await vn.symbols({ group: "VN30" });
const banks = await vn.symbols({ industry: "Ngân hàng" });
```

Mỗi phần tử:

```json
{
  "symbol": "FPT",
  "companyName": "Công ty Cổ phần FPT",
  "companyNameEn": "FPT Corporation",
  "exchange": "HOSE",
  "industry": "Phần mềm & Dịch vụ Máy tính",
  "industryEn": "Software & Computer Services",
  "sector": "Công nghệ Thông tin",
  "sectorEn": "Technology",
  "icbCode": "9537",
  "vn30": true
}
```

Danh mục mã được tải từ GitHub ở lần dùng đầu và cache trong `Storage`, nên `symbols()` không gọi VCI. Danh mục này cũng là thứ thư viện dùng để kiểm tra mã và gợi ý khi gõ sai.

Muốn bảng giá của cả nhóm thì dùng thẳng `vn.prices({ group: "VN30" })`.
