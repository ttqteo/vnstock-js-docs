**vnstock-js** là thư viện mã nguồn mở lấy dữ liệu chứng khoán Việt Nam cho JavaScript và TypeScript. Chạy trên Node, Bun, Deno, Cloudflare Workers, Vercel Edge, và trên trình duyệt qua proxy đóng gói sẵn.

```ts
import { vn } from "vnstock-js";

const fpt = vn.stock("FPT");
await fpt.price();        // { price: 127000, changePct: 0.95, ... }
await fpt.history("6mo"); // nến ngày, giá tính bằng đồng
await vn.market();        // VN-Index, thanh khoản, độ rộng, khối ngoại
```

👉 [vnstock-js trên npm](https://www.npmjs.com/package/vnstock-js) · [GitHub](https://github.com/ttqteo/vnstock-js) · [Trang demo vnstock-js-site](https://vnstock-js.vercel.app)

## Điểm chính của bản 2.0

- **Một API gọn**: `vn.stock('FPT')`, `vn.index('VNINDEX')`, `vn.market()`, `vn.screen()`... Không cần khóa API, không cần hàm khởi tạo.
- **Tiền luôn tính bằng đồng**, chỉ số tính bằng điểm, tỷ số là phân số. Xem [Quy ước & đơn vị](/docs/getting-started/conventions).
- **Chạy mọi nơi**: core dùng `fetch` có sẵn, không đụng ổ đĩa; trình duyệt đi qua proxy `vnstock-js/proxy`.
- **Dành cho AI agent**: JSDoc kèm ví dụ cho mọi API, `AGENTS.md` trong package, MCP server 27 công cụ.

## Tính năng

| Tính năng | Mô tả |
|---|---|
| Bảng giá, lịch sử giá | Giá hiện tại, nến từ 1 phút tới 1 tháng, gộp khung ngay trong thư viện |
| Thông tin công ty, tài chính | Hồ sơ, cổ đông, ban lãnh đạo, sự kiện, cổ tức, báo cáo tài chính |
| Thị trường | Tổng quan, độ rộng, thanh khoản, khối ngoại và lịch sử khối ngoại, thanh khoản trong phiên |
| Sàng lọc | Lọc theo P/E, ROE, vốn hoá... bằng `where` và `sort` |
| Chỉ báo & pattern | SMA, EMA, RSI, MACD, hỗ trợ/kháng cự, mẫu nến, Turtle, sức khoẻ thị trường |
| Danh mục đầu tư | Định giá theo giá hiện tại, nhóm theo môi giới và ngành |
| Theo dõi & cảnh báo | `watch()` qua WebSocket hoặc poll, `alert()` khi giá vượt đỉnh |
| Backtest | Event study với chốt lời, cắt lỗ, số phiên giữ; tìm phiên tương tự |
| Vàng, tỷ giá, tin tức | BTMC, GiaVang.net, Vietcombank, tin tài chính trong ngày |
| MCP & CLI | Dùng trong Claude, Cursor, VS Code; tra cứu nhanh trên terminal |

Đang dùng bản 1.x? Đọc [Nâng cấp từ v1](/docs/getting-started/migration).
